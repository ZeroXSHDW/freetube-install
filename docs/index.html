🖥 FreeTubeInstaller — the native Swift add-on

The same FreeTube system, as a real macOS app. It reads FreeTube's own databases, drives playback over freetube:// deep links and adds SponsorBlock auto-skip, an endless queue, sleep-aware pause, backups and a one-click doctor. Full source: github.com/ZeroXSHDW/freetube-install.

🗄DB syncHistory, subscriptions, favorites & watch-later straight from FreeTube.
⏭SponsorBlockAuto-skips sponsors, intros & filler while it plays.
🔁Endless queueDeep-links each chart track so the mix never stops.
😴Sleep-awarePauses on sleep, resumes on wake.
💾SnapshotsBackup/restore every FreeTube database + log cleanup.
🩺DoctorVerifies the stack and repairs common issues.

# Build & run from source
cd ~/Downloads/freetube-install && swift build

# Package a signed .app and install to ~/Applications
./scripts/build-app.sh --install

# Launch
open ~/Applications/FreeTubeInstaller.app

🔐 Gatekeeper note: the app is ad-hoc signed (like FreeTube itself). First launch: right-click → Open, or xattr -dr com.apple.quarantine ~/Applications/FreeTubeInstaller.app. The release zip includes a one-click Install FreeTubeInstaller.command that does this for you.
